膝盖曲柄连杆解析解推导

本页只解释计算过程。目标是证明：膝盖这套一自由度曲柄连杆机构不需要牛顿迭代，可以用二维几何的两个圆交点直接求出电机相对角。

机械零位: 小腿直立 theta_zero = 8.4 deg beta_zero = 61.2 deg r = 50 mm, a = 50 mm, L = 215 mm

摘要

机构中有四个关键点：膝盖轴中心 O、电机轴中心 M、曲轴端球心 E、膝盖输出小摇臂端球心 K。已知膝盖相对角 q_rel 后，可以直接算出 K。电机端点 E 必须同时落在两个圆上：以 M 为圆心半径 r 的曲轴圆、以 K 为圆心半径 L 的连杆圆。因此，反求电机角就是两个圆求交点。

1. 坐标系和已知量

只看膝盖侧视平面，使用二维坐标 [x, z]。膝盖转轴中心作为坐标原点。

O = [0, 0]
M = [M_x, M_z] = [0, 250]
x: 水平方向
z: 竖直方向

长度参数

r = 50 // 电机曲轴半径
a = 50 // 膝盖输出小摇臂半径
L = 215 // 长连杆长度

零位参数

q_rel = 0 时，小腿直立
motor_rel = 0 时，电机在机械零位
theta_zero = 8.4 deg
beta_zero = 61.2 deg

2. 为什么要区分相对角和绝对角

控制和编码器通常喜欢把机械直立姿态当成零位。但几何计算不能直接把所有角都当成零，因为曲轴和小摇臂在直立姿态下本来就有安装角。

theta_abs = theta_zero + motor_rel
beta_abs = beta_zero + q_rel

其中：

theta_zero = 8.4 deg
beta_zero = 61.2 deg

所以机械零位时：

q_rel = 0, motor_rel = 0
theta_abs = 8.4 deg
beta_abs = 61.2 deg

3. 给定两个角时，如何计算 E 和 K

3.1 曲轴端点 E

E 绕电机轴 M 转，半径是 r。

E_x = M_x + r * cos(theta_abs)
E_z = M_z + r * sin(theta_abs)
E = M + r [cos(theta_abs), sin(theta_abs)]

3.2 小摇臂端点 K

K 绕膝盖轴 O 转，半径是 a。

K_x = a * cos(beta_abs)
K_z = a * sin(beta_abs)
K = a [cos(beta_abs), sin(beta_abs)]

3.3 连杆长度约束

长连杆是刚体，所以 E 到 K 的距离永远等于 L。

|E - K| = sqrt((E_x - K_x)^2 + (E_z - K_z)^2) = L

4. 已知 q_rel，如何解析反求 motor_rel

这一步是关键。已知 q_rel 后，K 已经能直接算出来。未知的是 E 在曲轴圆上的位置，也就是 theta_abs。

1

先算 beta_abs

beta_abs = beta_zero + q_rel
2

再算 K 点

K = a [cos(beta_abs), sin(beta_abs)]
3

把问题变成两个圆交点

E 必须同时满足：

|E - M| = r
|E - K| = L

也就是：

圆 1: center = M, radius = r
圆 2: center = K, radius = L
4

定义从 M 指向 K 的向量 D

D = K - M = [D_x, D_z]
d = |D| = sqrt(D_x^2 + D_z^2)
phi = atan2(D_z, D_x)
5

用余弦定理求夹角 alpha

三角形的三个边长是：

M-K = d
M-E = r
K-E = L

在点 M 处，向量 M->K 和 M->E 的夹角叫 alpha。

cos(alpha) = (r^2 + d^2 - L^2) / (2 * r * d)
alpha = acos((r^2 + d^2 - L^2) / (2 * r * d))
6

得到两个候选曲轴绝对角

theta_abs_1 = phi + alpha
theta_abs_2 = phi - alpha

两个候选角对应两个圆交点。真实机构只能走其中一个分支。可视化里选择“离上一次电机角最近”的那个，避免跳到另一边。

7

把绝对曲轴角转成电机相对角

motor_rel = theta_abs - theta_zero
结论：膝盖这个机构是一自由度、二维曲柄连杆闭环，所以可以用两个圆交点解析求解，不需要牛顿法。

6. 最终算法

这段伪代码就是最终可以写进程序里的版本。

function solveMotorRel(q_rel):
  theta_zero = deg2rad(8.4)
  beta_zero = deg2rad(61.2)
  r = 50
  a = 50
  L = 215
  M = [0, 250]

  beta_abs = beta_zero + q_rel
  K = a * [cos(beta_abs), sin(beta_abs)]

  D = K - M
  d = norm(D)
  phi = atan2(D.z, D.x)

  if d > r + L or d < abs(r - L):
    return unreachable

  alpha = acos((r*r + d*d - L*L) / (2*r*d))
  theta_abs_1 = phi + alpha
  theta_abs_2 = phi - alpha

  theta_abs = choose_continuous_branch(theta_abs_1, theta_abs_2)
  motor_rel = theta_abs - theta_zero
  return motor_rel

7. 不可达条件和分支问题

两个圆不一定总有交点。判断条件是：

d > r + L // 两个圆离得太远
d < |r - L| // 一个圆完全包住另一个圆

只要出现这两种情况，机构在几何上不可达。此时不能强行算电机角，应该提示参数或目标角超出机构行程。

分支选择也很重要。公式会给出两个 theta_abs。真实机构不会瞬间穿过死点跳到另一个圆交点，所以控制程序要保持分支连续。最简单的方式是选择离上一帧电机角最近的候选角。
